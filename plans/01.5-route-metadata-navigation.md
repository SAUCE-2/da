# Plan 01.5: Route Metadata Navigation

## Goal

Add route metadata so the frontend can auto-generate navigation from `routeTree.gen.ts` instead of maintaining a separate nav config. This is a frontend-only bridge after Plan 01 and before Plan 02.

## What To Implement

- Add a shared nav metadata type in `frontend/src/types/router.ts`.
- Add `staticData.nav` to visible file routes.
- Add `frontend/src/lib/build-nav-tree.ts` to read nav metadata from the generated route tree.
- Replace the manual nav array in `frontend/src/routes/__root.tsx` with generated nav items.

## Nav Metadata Shape

```ts
type RouteNavMetadata = {
  id: string
  label: string
  subsectionId: string
  parentId?: string
  order: number
  hidden?: boolean
}
```

Routes without `staticData.nav` are ignored by the nav builder.

## Stable Nav IDs

Use stable dot-separated IDs and parent references:

```ts
nav: {
  id: 'audit.queries.detail',
  parentId: 'audit.queries',
  label: 'Query Detail',
  subsectionId: 'audit',
  order: 10,
}
```

Do not use URL paths as IDs or `parentId` values:

```ts
// Avoid
parentId: '/audit-queries'
```

## Parent And Child Routes

Parent/group route example:

```tsx
export const Route = createFileRoute('/reports')({
  component: ReportsLayout,
  staticData: {
    nav: {
      id: 'reports',
      label: 'Reports',
      subsectionId: 'audit',
      order: 30,
    },
  },
})
```

Child route example:

```tsx
export const Route = createFileRoute('/reports/sales')({
  component: SalesReportsPage,
  staticData: {
    nav: {
      id: 'reports.sales',
      parentId: 'reports',
      label: 'Sales',
      subsectionId: 'audit',
      order: 20,
    },
  },
})
```

## Hidden Routes

Omit `staticData.nav` for internal or detail routes. Only use `hidden: true` when a route must declare nav metadata for other reasons but should not appear in menus.

## Verification Checklist

- `npm run build` succeeds in `frontend/`.
- The header nav shows the same items in the same order as before.
- Each nav link navigates to the correct route.
- `routeTree.gen.ts` is not edited manually.
- No separate manual nav config remains in `__root.tsx`.

## Anti-Pattern Guards

- Do not use `useMatches()` to build the full primary nav; it only sees the active route chain.
- Do not use URL paths as nav identity.
- Do not add shadcn/sidebar components in this bridge unless the project already has them installed.
- Do not keep both manual nav config and generated nav config.
